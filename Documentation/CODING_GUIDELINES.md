# コードとドキュメントの規約

## 対象と基本書式

自作コード（`Assets/Bubbles/`、`Assets/Plugins/WebGL/`、`Assets/WebGLTemplates/`、`AgentScripts/`、`Tools/`）を対象とします。Unityのテンプレート、TextMesh Proなどの外部コード、ライセンス原文は変更しません。

`.editorconfig`を基本とし、UTF-8・LF・スペース4文字を使います。C#はMicrosoftの一般的な規約に沿って、波括弧を改行し、条件分岐とループには波括弧を付けます。1行に複数の文を詰め込みません。複雑な式の前提や意図は日本語コメントで説明します。

## 命名と互換性

- 型・メソッド・プロパティはPascalCase、引数・ローカル変数はcamelCaseとします。
- アクセス修飾子は明示します。新しい非公開フィールドはcamelCaseに統一します。
- 既存の公開フィールド名はUnityのシリアライズ、検証スクリプト、シーン参照との互換性のため維持します。変更が必要な場合は移行方法を用意します。
- メソッドは一つの役割を持たせ、更新順序と副作用が分かるようにします。単純な値の転送だけのメソッドは増やしません。

## 実行時の構成

`BubbleWorld`はシーンが参照する単一のMonoBehaviourを維持し、partialで実装を分けます。追加のコンポーネントやシーン移行を必要とせず、既存の状態と公開APIを共有できます。

| ファイル | 役割 |
| --- | --- |
| `BubbleWorld.cs` | 共有状態・初期化・設定・生成と破裂・ライフサイクル |
| `BubbleWorld.Input.cs` | マウスとタッチの読み取り、ジェスチャーの状態遷移 |
| `BubbleWorld.Simulation.cs` | 風・慣性・成長・補充・画面境界の計算 |
| `BubbleWorld.Rendering.cs` | 生成順の描画、位置・伸縮・シェーダー値の反映 |
| `BubbleWorld.Effects.cs` | 音声合成・サイズ別音量・破裂時の雫 |

`Tick`は成長、玉の移動・描画、補充、膨張音の順で更新します。風と静止空気の減衰は一度だけ積分し、その後に速度を制限します。装飾的な揺れと実際の速度は区別します。

`ParentSettings`という既存の型名は参照互換性のため維持しますが、画面上の文言には利用者層を限定する表現を使いません。

## 文書・検証

コメント、設計資料、作業手順、検証記録は日本語で書きます。API名・素材名・パスは原表記を保ちます。

変更後はUnityでコンパイルし、変更した責務に対応する`AgentScripts/Verify*.cs`を実行します。風の変更では慣性・影響範囲・見かけの移動、入力ではタップ・長押し・上限処理を確認します。Web出力を更新した場合は、グラフィックス有効のビルドと実ブラウザーのHDR背景確認を行います。未実施の検証は完了扱いにしません。
